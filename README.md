# Tshwane Water (website build)

Built files for https://psyphin.co.za/GP-water/ — an unofficial water-status site for City of
Tshwane suburbs. Not affiliated with the City of Tshwane, Rand Water, Magalies Water or DWS.

This repository only holds the generated website; it is published by GitHub Pages. Do not edit
these files by hand: they are replaced on every publish.
